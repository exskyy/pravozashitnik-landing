# Лендинг юридической компании «Правозащитник»
Адаптивный одностраничный сайт для юридической компании.  

## Демо
[https://exskyy.github.io/pravozashitnik-landing/]

## Особенности
- Mobile‑first, адаптив до 1920px
- Бургер-меню с оверлеем, закрытие по Escape
- Два слайдера с автопрокруткой (услуги – циклический, юристы – реверсивный)
- Чистый CSS, БЭМ, CSS-переменные
- Нет сторонних библиотек

## Используемые технологии
- HTML5, CSS3, JavaScript (ES6)
- Flexbox, Grid, медиа-запросы
